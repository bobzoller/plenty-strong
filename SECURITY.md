# Security

This repository publishes developmental source. There are no distributed or supported public app releases or verified public vulnerability-reporting endpoints yet.

Report a suspected vulnerability to the project owner through an existing trusted private channel. Do not send workout records, Apple identifiers, tokens, actual receipts or credentials. Give the affected source SHA, synthetic reproduction, impact and expected behavior. Do not post a sensitive issue publicly.

Use your existing trusted private channel to the project owner for sensitive reports. GitHub private vulnerability reporting has not been enabled or verified. Before app distribution, the owner must approve and verify a private reporting route, its monitored recipient and support/privacy destinations. Public source uses a new audited initial lineage; original private development ancestry remains local.

Local tests and unsigned builds require no credentials. CI must be read-only on ephemeral hosted runners, without production secrets or signing. No public-fork execution on credentialed self-hosted Macs. Publishing, signing, CloudKit deployment and distribution are separate approval gates.
