# Verified causal recovery

Downloads are untrusted immutable originals. RecoveryVerifier validates canonical asset bytes, dataset-scoped identities, embedded/archive hashes, frozen rules/profile references, exact parent input/revision, and full replayed state, prescription and decisions. It uses supplied archives and no clock. Schema 1 numeric observations retain their original omissions/rules; schema 2 retains independent variant identities, opaque descriptions and base safety. Unsupported or missing dependencies remain retained and block their affected program. Local-only training is complete.

CloudIngestor retains the full transport observations and sends a verifier-produced batch to the exclusive TrainingRepository writer. The writer re-verifies against its current durable originals and atomically commits graph, projections, originals and quarantine. Received journals never create upload-outbox rows. Independent programs/datasets coexist without selecting an active root. recoveryPrograms() exposes every candidate and its exact heads/projection/health for C3's explicit product selection.

Later truncated or tampered originals reopen the affected program through a unique fully replayed source with the exact actual zone/type/name. Embedded false program claims cannot redirect that association. Unknown or ambiguous provenance remains global quarantine. Candidate dataset IDs come from actual descriptors; only verified root manifests authorize selection, and candidates without verified heads cannot report ready. ArchiveV1 top-level program claims never create journal/root candidates.

Competing causal heads require an exact expected-head set. BranchSelection identifies the selected whole progression/configuration path; differing configuration/load/setup requires configurationHeadHash equal to selectedHeadHash. Incompatible exact UTF-8 descriptions for one variant require an explicit definition source. The resolver retains compatible distinct variants, clears comparable windows, rebaselines unpaused variants and unions all branch pain/control problems, pauses and stricter base restrictions. It never parses a load from text. CLOUD01 and cloud_resolution_* explanations are adapter decisions, separate from numeric R01–R16.

Invalid same-ID payloads remain permanent quarantine originals. reviewedQuarantineChecksums explicitly reviews the exact original byte hashes; invalid bytes are never accepted as history or selectable heads. New distinct heads or originals reopen conflict. Unsupported versions cannot be waived. Started/unfinished or ambiguous Finish drafts keep their original binding; resolution requires explicit removal of the local draft first. An unchanged repeated batch is idempotent. Saving append-only observations in an existing draft remains permitted while finalization/configuration are blocked.

Each local resolution creates content-addressed causal-original-v1 assets under the existing ArchiveV1 record type. A wrapper includes the exact original integrity descriptor/payload and a canonical contentHash excluding that field. Wrappers are one level deep and dataset-scoped. The resolution journals every wrapper reference and preserves every competing ancestor. Replay requires exact source coverage for all ancestor bytes and reviewed invalid originals. Missing, changed or nested wrappers never substitute a returned projection. Wrapper creation is bounded by the existing asset limit; an oversized package rejects resolution atomically.

Opaque invalid originals may contain arbitrary marker or claimed-dataset text and remain preservable after explicit review. Only an independently valid embedded source wrapper is forbidden nesting; its raw bytes are never recursively expanded. A retained descriptor actually belonging to another dataset cannot be wrapped into the selected dataset. Such resolution rejects and rolls back with every original still exportable. The complete assembled graph is verified inside the resolution transaction before save.

Exact acknowledged or independently verified fetched wrappers plus the required resolution may cover an occupied JournalV1 name. Its direct conflicting payload is never overwritten or falsely acknowledged. Once this exact source coverage is durable in the same scope, it can suppress that direct pending send. The residual transport conflict remains visible. Completed-workout recovery counts require every causal ancestor/source/frozen archive and the resolution itself. Portable semantic originals alone are not account-scoped download/ack evidence.

Ordinary linear exports keep format 1. Graphs, resolutions, multiple datasets or quarantine use format 2 with an explicit per-root dataset/head manifest; older format-1 readers must reject it. Portable files retain originals, all branches, quarantine, local drafts and resolutions. They exclude account bindings, system fields, CloudKit cursors/engine state and acknowledgement metadata.

Graph imports use the unique fully verified union head, so an ancestor or identical backup cannot replace a newer local descendant. Existing drafts and unresolved branches preserve the current projection. An incoming draft must validate against that actual retained projection; incompatibility rejects the transaction. The entire assembled export is validated before save, preserving the prior store on failure.

Within supported journal schemas, missing or type-invalid fields of known commands are invalid raw originals that require exact checksum review. Unknown journal/configuration/variant command discriminators remain unsupported boundaries. Numeric schema-1 configs can omit optional profile fields: supported continuation inherits missing archive references from the verified selected parent envelope and retains the original nil config fields and numeric rules. Missing references without that lineage produce typed invalid input.
