# Source and third-party attribution audit

Audit date: October 6, 2026. Plenty Strong code/assets use original project implementation and synthetic/design fixtures. The only package reference is the repository-local `Packages/TrainingCore`, whose Package.swift has no external dependencies. There is no third-party runtime SDK, remote package, vendored framework or bundled Kado artwork. No app icon or release screenshot is claimed ready by this audit.

[Kado](https://github.com/scastiel/kado) is product/design inspiration. Its current main resolves to `f3827a68f6e117ba9378f691f485260a4bdd7dae`; the [immutable MIT license](https://github.com/scastiel/kado/blob/f3827a68f6e117ba9378f691f485260a4bdd7dae/LICENSE) names Copyright (c) 2026 Sébastien Castiel. Source inspiration does not make him an author of Plenty Strong.

The audit compared local candidate file Git-blob hashes against the entire pinned Kado tree: no exact file matches. Focused comparison of six monetization/tip source files found no identical implementations or shared source lines longer than 55 characters. Manual review confirms Plenty Strong's separate receipt durability, immutable training journal, explicit recovery adapter and native views rather than imported Kado modules. These checks identify exact copying and inspect the relevant reference surface; they cannot establish historical authorship of every generic Swift idiom. No copied Kado material was identified, so NOTICE credits inspiration rather than inventing an incorporated copyright requirement. Any future approved source/asset copying must preserve the original MIT notice alongside the copied material and update this inventory.

Current Kado includes Supporter appearance benefits and nudges. Those features, upstream product/container/bundle IDs and branding are not part of Plenty Strong. Plenty Strong's `us.zoller.PlentyStrong` identifiers are proposed local candidate identifiers; team/products/container provisioning are still pending review. StoreKit configurations and screenshots in tests are synthetic.

Native frameworks used by production source are Foundation, SwiftUI, SwiftData, Observation, CryptoKit, CloudKit, StoreKit, UniformTypeIdentifiers and Darwin. They are Apple system frameworks, supplied under Apple's terms, not redistributed third-party SDKs. TrainingCore imports Foundation only. The original code is licensed under repository LICENSE (MIT, Plenty Strong contributors); NOTICE and native About carry attribution. Dependencies, binary links and shipped resources must be rechecked on the final signed archive before distribution.
